# 37% Sure: real cities in Minecraft, 1:1

Free Minecraft Java worlds from the 37% Sure YouTube channel: real cities at one block per meter, built by code from open map data
(nobody placed a block by hand).

| World | Video | Download |
|---|---|---|
| **Midtown Manhattan**: 4,018 buildings, the Empire State, Chrysler, Times Square | [watch](https://youtu.be/6PKTXaJRPlI) | [Manhattan-1to1-Minecraft-1.21.11.zip](https://github.com/akmiyata/37-sure-maps/releases/latest/download/Manhattan-1to1-Minecraft-1.21.11.zip) (75 MB) |
| **Seattle**: 15,922 buildings, every street and hill, the Space Needle | [watch](https://youtu.be/OQQVNCT5sVc) | [Seattle-1to1-Minecraft-1.21.11.zip](https://github.com/akmiyata/37-sure-maps/releases/latest/download/Seattle-1to1-Minecraft-1.21.11.zip) (269 MB) |

## Install
1. Minecraft **Java Edition 1.21.11**.
2. Unzip into your `saves` folder: Windows `%appdata%\.minecraft\saves`, macOS `~/Library/Application Support/minecraft/saves`,
   Linux `~/.minecraft/saves`.
3. Singleplayer → pick the world. You start in creative with cheats on.

Each world's `README.txt` has `/tp` commands to the views in the video, including the doors of the Empire State and the foot of
the Space Needle: the stairs go all the way up. Keep the world's data pack enabled; it raises the build height so the tallest
towers fit. A render distance of 16+ (or the Distant Horizons mod) shows the skyline.

Shapes and heights come from the map; facades and interiors are generated, and some heights are estimates.
